# Changelog

All notable changes to this project are documented in this file.

## v0.15.0-beta

### Features

- **Single card preview**: Added a preview dialog (the eye icon on a card) that
  shows how the card will look in Anki. It has Front/Back tabs, renders the
  card fields with the same styles as the exported deck, shows the video
  still image, and plays the exact audio that would be exported (including the
  configured tail padding). Cloze deletions are rendered as in Anki, and you
  can step through each cloze deletion with the number buttons.
- **Single card audio export**: Cards can now be exported one at a time as an
  mp3 file (the download icon on a card), instead of having to export a whole
  deck. The suggested file name is based on the card's transcription and the
  time range it covers.
- **Configurable clip tail padding**: Knowclip used to cut audio exactly where
  you drew the clip, which could cut off the tail of a sound. A new setting,
  "Extra time at the end of each clip", appends a configurable amount of time
  (500 ms by default) to every exported clip. For example, with a value of
  500, a clip from 00:00:01 to 00:00:03 actually exports 00:00:01 to
  00:00:03.5.
- **Keyboard clip resizing**: The selected card can be resized with
  `Shift` + `Left`/`Right` arrow. Holding `Alt` (or `Ctrl`) as well moves the
  *start* of the clip instead of its end. Each keypress moves the boundary by
  100 ms.
- **Explicit card merging**: Overlapping cards are no longer merged
  automatically when you drag them. They can now be merged deliberately with
  the merge button on the card (or the `M` key), so that cards which only
  partially overlap aren't accidentally combined.

### Fixes

- Anki decks are exported with the project name as the deck name, without an
  added "(Generated by Knowclip)" suffix.
- The app no longer shows an update notification every time it starts. Updates
  can still be checked manually from the Help menu.
- The app no longer crashes when devtools extensions fail to download.
