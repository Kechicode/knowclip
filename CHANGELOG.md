# Changelog

All notable changes to this project are documented in this file.

## v0.15.5-beta

### Features

- **Cloze note type**: A new project can use the Cloze note type. Each clip
  exports as one Anki card. The front plays the audio and gives a text box to
  type what you hear. The back compares what you typed with the original
  sentence, and shows meaning and notes when those fields have text. A card
  with no words selected yet asks you to type the whole sentence. Simple and
  Transliteration projects still export a listening card, and add a cloze card
  only when the card has deletions.

## v0.15.4-beta

### Features

- **Split a card at the playhead**: Press `K` while a card is selected and the
  playhead sits inside it. A dialog shows the two resulting time ranges; the
  first field starts with the original transcription and the second is empty.
  Saving shortens the original card and creates the card on the right. The
  audio file is cut from these times when you preview or export.
- **Place the playhead by dragging it**: Drag the playhead on the waveform.
  The time stays visible. `,` and `.` nudge it by 50 ms, and `Shift` makes
  that 10 ms. When it is inside the selected card, the readout shows how long
  each side would be.
- **Hear both sides before splitting**: `[` plays from the card start to the
  playhead, and `]` plays from the playhead to the card end. The playhead
  returns to the cut when the side finishes.

### Fixes

- **Previous card skips the current card's start**: Pressing `←` while the
  playhead is in the middle of a card selects the previous card.
- **Preview uses the card's own range**: Preview plays from the card's start
  to its end, so a split card does not include the next card. The extra time
  configured in settings is added only when exporting.
- **Preview refreshes after a card's times change**: The preview address
  includes the card's range, so a shortened card does not keep playing the
  audio from before the cut.
- **Export errors show the real message**: A failure while writing the Anki
  deck is reported as text instead of `Error: [object Event]`.

## v0.15.3-beta

### Fixes

- **Sequential new-card order in Anki exports**: Exported cards were all shown
  as `New #0`. They are now numbered in clip order (`New #0`, `New #1`, and so
  on), so Anki studies them in the order they were exported.

## v0.15.2-beta

### Features

- **More keyboard shortcuts in the card preview**: While the card preview is
  open, `←` and `→` switch between the front and the back of the card, and
  `Esc` closes the preview. The available shortcuts are listed at the bottom
  of the dialog.

## v0.15.1-beta

### Features

- **Keyboard shortcut for the card preview**: The preview dialog can now be
  opened with the `P` key for the selected card. The shortcut is listed in the
  app's keyboard shortcuts panel, and shown in the preview button's tooltip.
- **Play the preview audio with the space bar**: While the card preview is
  open, pressing `Space` plays (or pauses) the previewed card's audio instead
  of the media file.

## v0.15.0-beta

### Features

- **Single card preview**: Added a preview dialog (the eye icon on a card) that
  shows how the card will look in Anki. It has Front/Back tabs, renders the
  card fields with the same styles as the exported deck, shows the video
  still image, and plays the exact audio that would be exported (including the
  configured tail padding). Cloze deletions are rendered as in Anki, and you
  can step through each cloze deletion with the number buttons.
- **Single card audio export**: Cards can now be exported one at a time as an
  mp3 file (the download icon on a card), instead of having to export a whole
  deck. The suggested file name is based on the card's transcription and the
  time range it covers.
- **Configurable clip tail padding**: Knowclip used to cut audio exactly where
  you drew the clip, which could cut off the tail of a sound. A new setting,
  "Extra time at the end of each clip", appends a configurable amount of time
  (500 ms by default) to every exported clip. For example, with a value of
  500, a clip from 00:00:01 to 00:00:03 actually exports 00:00:01 to
  00:00:03.5.
- **Keyboard clip resizing**: The selected card can be resized with
  `Shift` + `Left`/`Right` arrow. Holding `Alt` (or `Ctrl`) as well moves the
  *start* of the clip instead of its end. Each keypress moves the boundary by
  100 ms.
- **Explicit card merging**: Overlapping cards are no longer merged
  automatically when you drag them. They can now be merged deliberately with
  the merge button on the card (or the `M` key), so that cards which only
  partially overlap aren't accidentally combined.

### Fixes

- Anki decks are exported with the project name as the deck name, without an
  added "(Generated by Knowclip)" suffix.
- The app no longer shows an update notification every time it starts. Updates
  can still be checked manually from the Help menu.
- The app no longer crashes when devtools extensions fail to download.
